# ElectroHub-PowerBI-Dashboard
Built an interactive Power BI dashboard for ElectroHub to analyze sales, profit, and customer trends. Implemented time-based comparisons, top/bottom product analysis, discount insights, and city-wise performance, enabling data-driven business decisions.

# 📊 ElectroHub Power BI Dashboard

## 🔍 Project Overview
This project analyzes sales, profit, and customer behavior using Power BI.

## 📌 Features
- Top/Bottom 5 products analysis
- Sales trends (daily, monthly, yearly)
- Sales vs Profit analysis
- Time period comparison
- Discount analysis
- City-wise sales insights

## 🛠 Tools Used
- Power BI
- DAX
- Data Modeling

## 📈 Key Insights
- Identified top-performing products
- Found seasonal sales trends
- Observed impact of discount on profit
